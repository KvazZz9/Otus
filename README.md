Реализован прект с инпользованием tofy/ansible/git.
В данной ветки расположен процесс поднятия балансировщика, 2х апп серверов, и nfs + drbd + pacemaker кластера.
Сама база данных с балансировщиком поднимается также автоматизировано и описано  в ветке https://github.com/KvazZz9/Otus/tree/6.Postgres .
Порядок  прогона ролей :
1) поднимаем кластер postgres из ветки https://github.com/KvazZz9/Otus/tree/6.Postgres
2) поднимаем nfs + drb + pacemaker ( стадия гита nfsup )
3) поднимаем app сервера

Балансировщик преред апп серверами настроен на проверку доступности апп серверов и перенаправление на доступный + добавлена балансировка по ip адресу ( требование Nexcloud).

Также благодаря тому, что в процессе настройки апп серверов к ним примапливается папка с нфс серверов через vip ip , после чего на нее копируются непосредственно данные nexctcloud обеспечивается синхронизация и резервирование статических данных .
При выключение 1 из app серверов сервис продолжает работать через другой.

Прив выключение master nfs сервера происходит автоматическое переключение ресурсов на slave сервер и активация его как мастер, происходит отказ сервиса на 1 минуту после чего сервис nexcloud продолжает работать без потери даныых. Скриншот вложил.
