Поднимаю полностью пг кластер через гит и ансибл.
В него входят 5 вм, 2 балансировщика ha работающие через vip ip keeplived на входе. Сами балансровщики дергают апи патрони по порту 8008 на предмет выявления мастера и ои перенаправляют запрос на нужный сервер пог порту pgbouncer 6432 , pgbouncer стоит на каждой ноде и перенаправляет входящи запрос непостредственно в постгре по стандартному порту 5432. В данную схему можно было собрать без pgbouncer но тут он используется для оптимизации количества входящих одновременных подключений.
Сам кластер пг стандарт - етсд 3 ноды и патрони.
Кластер встроен в проектную работу которую защитил и корректно функционирует. Приложил скрины схемы и проверки работоспособности.
